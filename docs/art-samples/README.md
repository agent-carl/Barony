## Палитра (черновой стиль-гайд)

Принцип: **холодный сине-серый камень + один тёплый акцент — газовый свет.**
Мир по умолчанию холодный и мёртвый; всё тёплое означает безопасность.
Это напрямую поддерживает механику света/тьмы (docs/LIGHT_AND_DREAD.md).

Витраж и газовый рожок — единственные тайлы, которым разрешён цвет
за пределами холодной гаммы: святое и домашнее светятся. Всё прочее
намеренно приглушено.

Правила стиля:
- Тайлы 32×32, без сглаживания, масштабирование только nearest-neighbor.
- Свет на камне: блик слева-сверху, раствор справа-снизу (единое
  направление света во всех тайлах).
- Шум ±6 яркости на пиксель — «ручная» фактура без грязи.
- Тёплые цвета (латунь/пламя) — только у источников света и наград.
