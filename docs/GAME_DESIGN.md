# Project Umbra — Game Design Document

> Рабочее название. Форк на движке Barony (BSD 2-Clause). Цель — самостоятельная
> кооперативная survival-horror игра для релиза в Steam.

## 1. Высокоуровневое видение

**Жанр:** кооперативный survival-horror dungeon-crawler от первого лица.
**Сеттинг:** тёмный (sci-fi / готика), с упором на механику света и тьмы, ресурс
и атмосферу. Точный сеттинг фиксируется отдельно; пока — «мрачные глубины».
**Игроки:** 1–4 в кооперативе (онлайн + сплит-скрин, оба режима уже в движке).
**Основа лупа:** исследование процедурно-собранных уровней, выживание, ресурсы,
магия, крафт и «билды» персонажа, продвижение по сюжету.

### Ключевые столпы
1. **Свет против тьмы** — темнота опасна и ресурсна; освещение = безопасность и цена.
2. **Кооп на 1–4** — играбельно и в одиночку (см. компаньон), и командой.
3. **Билды и крафт** — глубина прогрессии через предметы, магию, крафт.
4. **Сюжетный костяк** — игроки двигаются по нарративу, а не по бесконечному гринду.

## 2. Что берём из движка Barony (уже готово)

Проверено в исходниках — эти системы существуют и переиспользуются:

| Система | Где | Статус |
|---|---|---|
| Рендер OpenGL 3.2 core + HDR | `opengl.cpp`, `shader.cpp` | готово |
| Динамическое освещение | `light.cpp` | готово, ключ к теме свет/тьма |
| Предметы / инвентарь | `items.cpp`, `item_*.cpp` | готово — **сохраняем** |
| Магия / заклинания | `magic/`, `scrolls.hpp` | готово — **сохраняем** |
| Крафт | система предметов | база есть — **расширяем** |
| Монстры / ИИ | `monster_*.cpp`, `actmonster.cpp` | готово, реассет под сеттинг |
| **Компаньон с приказами** | `FollowerMenu`, `ALLY_CMD_*` | **готово — см. §3** |
| Кооп-сеть + сплит-скрин | `net.cpp`, `player.cpp` | готово |
| Генерация уровней | `maps.cpp` | готово, свои тайлы/структуры |
| Steamworks (ачивки, облако) | `steam.cpp` | готово, включается флагом |
| Редактор уровней | `editor.cpp` | готово — инструмент для сюжетных карт |

## 3. Фича «Соло-компаньон» (переиспользование, не разработка с нуля)

Движок уже содержит полноценную систему приказов союзникам — `FollowerMenu` с
командами: `ALLY_CMD_FOLLOW`, `ALLY_CMD_DEFEND`, `ALLY_CMD_MOVETO`,
`ALLY_CMD_ATTACK`, `ALLY_CMD_PICKUP_TOGGLE`, `ALLY_CMD_DROP_EQUIP` и др.
(см. `actmonster.cpp`, `interface/`).

**Что нужно доработать (а не написать заново):**
- Автоспавн компаньона при старте одиночной игры.
- Настройка ИИ-помощника (боёвка, подбор, следование) под баланс соло.
- Привязка компаньона к нарративу (персонаж с ролью в сюжете).
- UX колеса приказов под соло-режим.

## 5. Юридические рамки (критично)

- Код Barony — **BSD 2-Clause**: форк, закрытие своего кода и коммерческий релиз
  разрешены. Обязательство — сохранить копирайт Turning Wheel в исходниках/доках.
- **Ассеты Barony (модели, спрайты, звук, тексты, карты) — проприетарны** и в
  репозитории отсутствуют (грузятся из купленной Steam-копии). Для релиза **весь
  контент должен быть заменён на оригинальный**.
- Аудио: уходим с FMOD (требует регистрации/атрибуции) на OpenAL (свободный).

## 6. Открытые вопросы
- Точный сеттинг и визуальный стиль (sci-fi vs готика vs смесь).
- Финальное название игры.
- Источник ассетов: свой художник / покупные / генеративные / минимализм-стиль.
- Модель нарратива: линейные акты vs хабы с ветвлением.
