# Свет и Страх (Light & Dread) — дизайн-спека ядра хоррора

> Ключевой столп Project Umbra: тьма — не косметика, а давление.
> Свет — расходуемый ресурс безопасности. Механика должна читаться без
> обучалки: темно → тревожно → опасно; светло → безопасно.

## 1. Петля механики

```
игрок в темноте → растёт Страх (Dread) → шёпоты, дебаффы, урон психики
игрок у света   → Страх спадает      → безопасность, восстановление
источники света → расходуются/гаснут → нужно топливо (крафт) → вылазки во тьму
```

Тьма выталкивает к свету, ресурс света выталкивает во тьму. Цикл напряжения.

## 2. Измерение освещённости

Движок уже считает по-тайловую освещённость: `Entity::entityLight()`
(`entity.cpp:531`) возвращает 0–255 для клетки сущности из `lightmaps[0]`
(глобальная карта, серверная — её же использует ИИ монстров для зрения).
Никакого нового рендер-кода не нужно.

| Диапазон L | Зона | Смысл |
|---|---|---|
| L < 32 | **Тьма** | Страх растёт |
| 32 ≤ L < 96 | Сумрак | Страх медленно спадает |
| L ≥ 96 | **Свет** | Страх быстро спадает |

## 3. Шкала Страха (Dread), 0–100, на игрока

Серверная величина, тик раз в секунду (`TICKS_PER_SECOND`):

| Условие | Изменение/с |
|---|---|
| Тьма | +3, +1 за каждые 5 этажей глубины |
| Сумрак | −1 |
| Свет | −5 |

### Пороги и эффекты

| Порог | Стадия | Эффект (MVP) | Эффект (позже) |
|---|---|---|---|
| 25 | Тревога | шёпот-сообщение | звуковой шёпот (OpenAL) |
| 50 | Дрожь | сообщение | −PER/−точность, виньетка |
| 75 | Ужас | сообщение | шанс EFF_FEAR, усиленные спавны |
| 90 | Поглощение | 2 урона психики / 3 с (не убивает: минимум 1 HP) | галлюцинации-фантомы |

Правила:
- Тьма сама по себе **не убивает** (пол HP = 1) — она доводит до
  предсмертного состояния; убивает то, что приходит из тьмы. Это честно
  и сохраняет напряжение без дешёвых смертей.
- Сообщения о порогах — только при пересечении вверх (без спама).
- Сброс: новый уровень — страх /2; смерть/новая игра — 0.
- Мультиплеер: сервер считает для всех, сообщения через `messagePlayer`
  (работает по сети из коробки). У каждого игрока — своя шкала: группу
  можно разделить светом, это осознанный кооп-дизайн.

## 4. Свет как ресурс (этап 1.2, после MVP)

- Факелы/лампы в руке — уже в движке (шейп `TOOL_TORCH`, `TOOL_LANTERN`).
  Добавляем: конечное «топливо», расход в реальном времени, крафт масла.
- Настенные источники: гаснут навсегда (обыскал этаж — унёс свет с собой).
- Викторианский флейвор: газовые рожки на стенах хабов — вечные островки
  безопасности; переносной свет — расходник.

## 5. Реализация MVP (этот заход)

- `src/dread.cpp` + `src/dread.hpp` — вся логика, отдельно от легаси.
- Хук: `dreadUpdate()` из `gameLogic()` (game.cpp), внутренние гарды:
  сервер/сингл, не пауза, не интро, режим по умолчанию.
- Состояние: статический массив на игрока, вне сейвов (MVP).
- Константы — в одном месте сверху файла, под будущие ConsoleVariable.

## 6. Что сознательно НЕ в MVP

Звук шёпотов, виньетка/зерно на клиенте, влияние на спавны, влияние
компаньона на страх (компаньон рядом = −25% скорости роста — идея),
сейв/лоад шкалы, настройки сложности.
