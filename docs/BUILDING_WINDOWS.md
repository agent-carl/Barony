# Project Umbra — запуск на Windows

> ⭐ **Самый простой путь — предсобранный билд.** Я кросс-компилирую
> `umbra.exe` под Windows прямо из Linux (MinGW-w64 + библиотеки MSYS2),
> так что тебе **не нужны ни Visual Studio, ни vcpkg**. Просто скачай
> архив, который я присылаю в чат, и следуй `READ_ME_FIRST.txt` внутри:
> скопировать в копию папки Barony и запустить. См. раздел **«Вариант A»**.
>
> Инструкция ниже (Вариант B) — на случай, если хочешь собирать сам.

## Вариант A. Готовый билд (рекомендуется)

1. Скачай `umbra-windows.zip` (присылаю в чат).
2. Найди папку Barony: Steam → ПКМ по Barony → Управление →
   Посмотреть локальные файлы.
3. Скопируй ВСЮ эту папку в новое место, напр. `C:\umbra-play`
   (оригинал не трогаем — сейвы у форка и так отдельные, `~/.umbra`).
4. Распакуй содержимое `umbra-windows.zip` в `C:\umbra-play`
   (заменить `lang\en.txt`, если спросит).
5. Запусти `umbra.exe`. Заголовок окна — **Project Umbra**.

Если не стартует — пришли `C:\umbra-play\log.txt` (или
`C:\Users\<ты>\.umbra\log.txt`). Это первый кросс-собранный бинарь,
сюрпризы возможны — лог покажет, что чинить.

Как воспроизвести кросс-сборку самому (на Linux):
`tools/build-windows-cross.sh` — стейджит Windows-библиотеки из MSYS2,
собирает `build-win/umbra.exe` и складывает полный набор DLL в
`build-win/dist/`.

## Вариант B. Собрать самому на Windows

> Инструкция рассчитана на первый раз: каждый шаг с проверкой результата.
> Общее время: ~1–1.5 часа, из них большая часть — ожидание установок.
> Если на любом шаге что-то не совпало с «Проверкой» — стоп, скопируй
> текст ошибки/последние 30 строк вывода и пришли мне. Не отлаживай сам.

## Часть 0. Установка инструментов (один раз, ~30–40 минут)

### Шаг 0.1 — Visual Studio 2022 Community (компилятор C++)

1. Открой https://visualstudio.microsoft.com/ru/downloads/
2. Скачай **Visual Studio 2022 Community** (бесплатная) и запусти установщик.
3. В окне выбора компонентов найди вкладку **«Рабочие нагрузки»** и поставь
   галочку на **«Разработка классических приложений на C++»**
   (англ.: *Desktop development with C++*).
4. Справа в списке «Сведения об установке» убедись, что среди компонентов
   есть **«C++ CMake tools for Windows»** (обычно включён по умолчанию).
5. Жми «Установить». Займёт ~10 ГБ и 15–30 минут. Перезагрузись, если попросит.

**Проверка:** в меню «Пуск» появился пункт
**«Developer PowerShell for VS 2022»**. Он нам понадобится — именно в нём
живёт cmake (в обычном PowerShell его НЕ будет, это нормально).

### Шаг 0.2 — Git

1. Открой https://git-scm.com/download/win — скачается установщик.
2. Запусти, во всех окнах жми «Next» (настройки по умолчанию подходят), «Install».

**Проверка:** открой «Developer PowerShell for VS 2022» (Пуск → набери
`developer` → выбери его) и введи:

```powershell
git --version
cmake --version
```

Обе команды должны напечатать версии (например `git version 2.45...` и
`cmake version 3.29...`). Если `cmake` «не является командой» — ты в обычном
PowerShell, открой именно **Developer PowerShell for VS 2022**.

> ⚠️ **Все следующие команды вводим в Developer PowerShell for VS 2022.**

### Шаг 0.3 — Barony в Steam

Убедись, что Barony установлена. Узнай её папку: Steam → библиотека →
ПКМ по Barony → **Управление → Посмотреть локальные файлы**. Откроется
проводник — скопируй путь из адресной строки (обычно
`C:\Program Files (x86)\Steam\steamapps\common\Barony`). Запомни его,
пригодится в Части 3.

## Часть 1. vcpkg — менеджер C++-библиотек (один раз, ~30–40 минут)

### Шаг 1.1 — установить vcpkg

Вводи команды по одной, дожидаясь окончания каждой:

```powershell
git clone https://github.com/microsoft/vcpkg C:\vcpkg
```
*(~1 минута; в конце — «done.»)*

```powershell
C:\vcpkg\bootstrap-vcpkg.bat
```
*(~1 минута; в конце — «vcpkg package management program version ...»)*

### Шаг 1.2 — собрать зависимости

Одна длинная команда (скопируй целиком, это одна строка):

```powershell
C:\vcpkg\vcpkg install --triplet x64-windows sdl2 sdl2-image sdl2-net sdl2-ttf physfs rapidjson libpng zlib openal-soft libvorbis libogg opengl
```

Это **самый долгий шаг**: 20–40 минут, много текста про «Building...».
Можно уходить пить чай — вмешательство не требуется.

**Проверка:** в конце вывода — список «The following packages are already
installed» / «... successfully installed», и команда завершилась без
красного текста `error`.

## Часть 2. Скачать и собрать Umbra (~10 минут)

### Шаг 2.1 — клонировать репозиторий и переключиться на нашу ветку

```powershell
cd C:\
git clone https://github.com/agent-carl/Barony umbra
cd C:\umbra
git checkout claude/game-customization-graphics-t0ykbi
```

**Проверка:** последняя команда напечатала
`branch 'claude/game-customization-graphics-t0ykbi' set up to track...`
или `Switched to a new branch ...`.

### Шаг 2.2 — сконфигурировать сборку

Скопируй блок целиком (обратные кавычки в конце строк — перенос строки
в PowerShell, это нормально):

```powershell
cmake -B build -S . `
    -DCMAKE_TOOLCHAIN_FILE=C:\vcpkg\scripts\buildsystems\vcpkg.cmake `
    -DFMOD_ENABLED=OFF `
    -DOPENAL_ENABLED=ON `
    -DSTEAMWORKS_ENABLED=0 `
    -DEOS_ENABLED=0 `
    -DPLAYFAB_ENABLED=0
```

*(~1–2 минуты)*

**Проверка:** в конце вывода строки
`-- Configuring done` и `-- Generating done`. Если вместо этого красный
`CMake Error` — пришли мне последние 30 строк.

### Шаг 2.3 — собрать игру

```powershell
cmake --build build --config Release -j
```

*(~5–10 минут, сотни строк «.cpp». Предупреждения (warning) — нормально,
их много и они не мешают.)*

**Проверка:**

```powershell
dir C:\umbra\build\Release\umbra.exe
```

Файл существует, размер ~10–20 МБ. Если сборка оборвалась со словом
`error` — последние 30 строк мне.

## Часть 3. Папка для игры (~2 минуты)

Игре нужны ассеты (модели/звуки/карты) из твоей Steam-копии Barony.
Мы делаем **копию** папки — оригинальная установка не пострадает
(сейвы форк и так пишет отдельно).

```powershell
Copy-Item -Recurse "C:\Program Files (x86)\Steam\steamapps\common\Barony" C:\umbra-play
```
*(путь в кавычках замени на свой из шага 0.3, если отличается; ~1 минута)*

```powershell
Copy-Item C:\umbra\build\Release\umbra.exe C:\umbra-play\
Copy-Item C:\umbra\lang\en.txt C:\umbra-play\lang\ -Force
```

**Проверка:**

```powershell
dir C:\umbra-play\umbra.exe
dir C:\umbra-play\models\models.txt
```

Обе команды находят файлы. Вторая подтверждает, что ассеты на месте.

## Часть 4. Запуск (~1 минута)

```powershell
cd C:\umbra-play
.\umbra.exe
```

**Проверка, что это наш форк:**
- заголовок окна — **Project Umbra**;
- игра дошла до главного меню без вылета;
- (после первого запуска) существует файл `C:\umbra-play\log.txt`,
  и в нём есть строка `Project Umbra version: ... (Based on Barony ...)`.

Если игра вылетела или чёрный экран — закрой её, пришли мне **весь**
`C:\umbra-play\log.txt`.

## Часть 5. Плейтест: что и как проверять

Начни **новую одиночную игру** любым классом. Дальше по списку, по порядку —
от простого к сложному. Управление — как в Barony (WASD, мышь, ПКМ —
взаимодействие).

### 5.1 Компаньон (первые 2 минуты)
- [ ] Рядом со стартом стоит человек **с лампой** в руке. Имя зависит от
  твоего класса: воинам — Doctor Rosalind, магам — Sergeant Briggs,
  прочим — Mordecai.
- [ ] Наведись на него и зажми ПКМ — колесо приказов (Follow / Wait /
  Attack / Move to). Дай пару приказов, посмотри, слушается ли.
- [ ] Сообщение при старте: «... joins you. Interact with them to give orders.»

### 5.2 Страх и темнота (5 минут)
- [ ] Найди тёмный угол подальше от факелов и **стой** в нём.
- [ ] Спутник скажет: «Stay close, sir. And mind the dark.»
- [ ] Пойдут шёпоты по нарастающей: «The darkness presses in...» (25) →
  «Your hands are shaking...» (50) → «Terror claws at your mind...» (75).
- [ ] **Края экрана темнеют** (виньетка) — тем сильнее, чем выше страх.
- [ ] На 90+: «The dark is inside you now», периодический **урон** (HP не
  упадёт ниже 1) и **тряска камеры**.
- [ ] Вернись к свету — страх спадает, виньетка уходит.

### 5.3 Тень (10 минут — самое интересное)
Чтобы не ждать, ускорь страх: нажми **Enter** (откроется строка сообщений)
и введи `/dread_rise 20`. Теперь страх взлетает за секунды.
- [ ] На страхе 100: «The darkness takes shape. Something is hunting you.»
  — где-то рядом заспавнилась теневая тварь и идёт к тебе.
- [ ] Замани её к настенному факелу/светлому месту: «The light sears the
  shadow!» — она получает урон и **шарахается прочь от тебя**.
- [ ] Убей её (или сбеги к костру, см. 5.4): «The shadow is gone. You can
  breathe again.» — страх упал до 50.
- [ ] Верни норму: `/dread_rise 3`.

### 5.4 Костёр-святилище
- [ ] Найди костёр (встречаются в подземельях и у торговцев).
- [ ] При подходе: «The fire's warmth pushes back the dark», страх тает
  на глазах.
- [ ] Если привёл Тень к костру: «The shadow cannot abide the hearth» —
  изгнана.

### 5.5 Свет как ресурс
- [ ] Возьми факел в руку (слот щита). Подожди ~90 секунд игры: сообщение
  об износе факела. Через 4 ступени он гаснет и исчезает из руки.
  (Ускорить: `/torch_stage_seconds 10`.)
- [ ] Сними факел **со стены** (ПКМ по настенному факелу) — на стене
  осталось тёмное крепление.
- [ ] Имея запасной факел в рюкзаке, кликни по тёмному креплению:
  «You fix a torch in the cold sconce. Light returns to the wall.»

### 5.6 Остальное (по желанию)
- [ ] Заклинания на страхе 75+ бьют ощутимо сильнее (до +30%).
- [ ] Проклятый предмет в экипировке — страх в темноте растёт быстрее.
- [ ] ~3 минуты рядом со спутником: реплика доверия «I'm glad it's you
  down here with me, sir.»
- [ ] Если спутник погиб: «Your companion is gone. The dark feels heavier
  now» — и это правда ощущается в скорости страха.
- [ ] Пережить 90+ страха и успокоиться до ~20: «The dark has left its
  mark on you...» — шрам разума.
- [ ] Звук: музыка и эффекты играют (это наш OpenAL-порт — важно!).

## Часть 6. Живая настройка баланса

В игре: **Enter** → вводи команду → Enter. Значения сохраняются до
перезапуска.

| Команда | По умолчанию | Что делает |
|---|---|---|
| `/dread_rise 2` | 3 | рост страха в темноте, ед/сек |
| `/dread_fall_dim 2` | 1 | спад в сумраке |
| `/dread_fall_bright 8` | 5 | спад у яркого света |
| `/dread_light_dark 40` | 32 | порог «темно» (0–255) |
| `/dread_light_bright 90` | 96 | порог «светло» |
| `/stalker_spawn_dread 60` | 100 | страх появления Тени |
| `/stalker_sear_damage 30` | 20 | урон Тени от света, ед/сек |
| `/stalker_cooldown 30` | 90 | пауза между Тенями, сек |
| `/torch_stage_seconds 30` | 90 | сек на ступень износа факела |
| `/lantern_stage_seconds 60` | 240 | то же для лампы |

Играй и записывай значения, которые «сидят» по ощущениям — вобью их
как новые дефолты.

## Часть 7. Если что-то пошло не так — что мне прислать

| Ситуация | Что прислать |
|---|---|
| Ошибка на шаге установки/сборки | последние ~30 строк из окна PowerShell (выдели мышью → Enter копирует) |
| Игра не стартует / вылетела | весь файл `C:\umbra-play\log.txt` |
| Механика работает не так | скриншот + что делал + что ожидал |
| Всё работает 🎉 | впечатления: где страшно, где скучно, какие цифры баланса поставил |

Ничего не чини сам — просто шли материал, я разберу и выпущу фикс,
тебе останется `git pull` + повторить шаги 2.2–2.3 и копирование exe.
